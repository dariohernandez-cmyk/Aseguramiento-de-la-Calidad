Historia 1: Registro de usuario
Como visitante de la aplicación
Quiero crear una cuenta con mi correo y contraseña
Para poder acceder a las funcionalidades personalizadas.

Criterios de aceptación:

El sistema debe validar que el correo no esté registrado previamente.

La contraseña debe cumplir con requisitos mínimos (ej. 8 caracteres, incluir número).

Al registrarse correctamente, se muestra un mensaje de confirmación.
